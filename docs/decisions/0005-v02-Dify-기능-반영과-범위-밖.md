# ADR 0005. v0.2 Dify 기능 반영과 범위 밖 항목

- 상태: 채택
- 날짜: 2026-11-03

## 배경
사용자 요청: "Dify에서 제공하는 기능들을 상세히 조사해서 다 추가, 소유자·관리자 전용 관리 기능 추가". 조사 결과와 반영 범위는 `docs/dify-gap.md`.

## 결정
- 노드 10종(질문 분류·값 뽑아내기·글 틀·값 모으기·목록 다루기·항목마다 반복·되풀이·파일 읽기·대화 변수 저장·에이전트)과 노드 공통 재시도·실패 처리를 추가한다. 모두 기존 NodeSpec 인터페이스를 쓴다.
- 반복·되풀이는 Dify처럼 하위 그래프를 그리지 않고 "하위 동작 1개"(llm, template, http, code, knowledge_search, parameter_extractor, connector)를 항목마다 실행한다. 캔버스·검증·실행을 단순하게 유지하기 위해서다.
- 주석 답변의 비슷한 질문 판단은 임베딩 대신 글자 유사도(difflib, 기본 0.85)로 한다. AI 키 없이도 동작하고 비용이 없다.
- 키워드 검색은 PostgreSQL 전문 검색 대신 단어·두 글자 조각 일치율로 계산한다(한국어 형태소 분석기 없이도 동작).
- 재정렬(rerank)은 별도 rerank 모델 대신 기본 AI 연결로 순서를 다시 매긴다(켜면 비용 발생).
- 음성 입력·읽어 주기는 브라우저 기능(Web Speech API)으로 한다. 서버 비용이 없다.
- 관리 콘솔의 시스템 설정은 "인스턴스 관리자"(가장 먼저 만든 워크스페이스의 소유자)만 바꾼다.
- DB는 추가만 했다(마이그레이션 0004, downgrade 포함).

## 범위 밖(후보)
- 외부 추적 연동(Langfuse·LangSmith·Opik·Arize), MCP 서버로 게시
- Knowledge Pipeline, Q&A 청킹
- 병렬 분기 실행, 하위 그래프를 그리는 반복 노드
- Dataset Operator 역할, 결제·요금제·SSO(CLAUDE.md 제외)

## 영향
- 노드 19종, 테스트 191개(Python)·19개(웹).
- 빌더 시스템 프롬프트에 새 노드 규칙을 추가했다. 데모 시나리오 3개 녹화 테스트는 그대로 통과한다(시나리오 2는 출처 이벤트가 추가됨).
