# ADR 0011. 오픈 준비 — 계정 스스로 관리·처음 쓰는 사람 안내·운영 안정성

- 상태: 채택
- 날짜: 2026-11-04

## 배경
사용자가 "실제 오픈할 때 부족한 기능을 확인해 추가"해 달라고 요청했다. 코드와 운영 환경을 점검한 결과는 다음과 같다.
- 기능 범위는 Dify·n8n 수준에 가깝다.
- 다만 혼자 시작하고 믿고 맡기는 데 필요한 기본기가 비어 있었다.
  - 계정: 비밀번호 찾기, 이메일 인증, 2단계 인증, 탈퇴가 없었다.
  - 안내: 첫 사용 안내 장치가 부족했다.
  - 법적 고지: 약관이 없었다.
  - 운영: 자동 백업, 시스템 상태 화면, 서버 오류 기록, CSP가 없었다.

## 결정
1. **계정 스스로 관리**
   - 시스템 메일(SMTP)을 설정한다. 비밀번호는 암호화해 저장한다.
   - 비밀번호 찾기: 일회용 토큰을 해시로 저장하고 30분 뒤 만료한다. 가입 여부는 드러내지 않는다.
   - 이메일 인증은 선택 항목이다(기본은 끔).
   - 2단계 인증은 TOTP(RFC 6238)로 하고 복구 코드 10개를 준다.
   - 로그인 기기 목록을 보여 주고, 기기별 로그아웃과 전체 로그아웃을 할 수 있게 한다.
   - 내 데이터를 내려받거나 탈퇴할 수 있다. 다른 멤버가 있는 워크스페이스의 유일한 소유자는 탈퇴를 막는다.
   - 마이그레이션은 0010이다.
2. **처음 쓰는 사람 안내**
   - 첫 로그인 때 화면 투어를 보여 준다(역할에 맞춰서).
   - 대시보드에 시작 체크리스트를 둔다. 진행 상황은 개인 설정에 저장한다.
   - 빈 화면마다 다음 행동을 안내한다.
   - 도움·문의 창을 둔다. 보낸 의견은 활동 기록(`feedback.send`)에 남긴다.
   - 이용약관·개인정보처리방침 초안과 가입 동의 절차를 둔다. 법률 검토가 필요하다는 표시를 붙인다.
   - 404 화면과 오류 화면을 둔다.
3. **운영 안정성**
   - 매일 DB 자동 백업을 하고 7일치를 보관한다. 복구 스크립트를 함께 둔다.
   - 관리 > 시스템 상태 화면을 둔다.
   - 서버 오류 기록(`error_events`)을 남기고 30일 보관한다. 응답에는 요청 번호를 붙인다. 마이그레이션은 0011이다.
   - CSP를 넣는다. 위젯·공유 경로만 다른 사이트에 넣을 수 있게 한다.
   - 활동 기록을 CSV로 내보낼 수 있게 한다.

## 범위 밖으로 남기는 것 (판매형 전환 때 결정 필요)
- 실제 결제·요금제, 사용량 과금
- 기본 제공 AI와 체험 크레딧
- SSO
- 고객사별 데이터 격리(멀티테넌트 인프라)
- 클라우드 서버로 이전

CLAUDE.md의 '하지 않는 것'에 해당하거나 외부 계약이 필요한 항목이다. 사용자 결정 뒤 별도 ADR로 다룬다.

## 영향
- 메일 설정이 없으면 비밀번호 찾기와 이메일 인증을 쓸 수 없다. 이 경우 "관리자에게 요청하세요" 안내로 대신한다.
- 로그인 상태를 서버에 기록한다(기기 관리용). 그래서 강제 로그아웃이 가능해진다.
