# ADR 0013. Dify 격차 3차 — v0.9

- 상태: 채택
- 날짜: 2026-11-05

## 배경
ADR 0012(v0.8) 이후 비교 목록에 '다음'으로 남은 7개 항목을 모두 구현하라는 요청을 받았다(2026-11-05).

## 결정
1. **캔버스 동시 편집·댓글**
   - 같은 앱을 여러 명이 열면 서로 누가 보고 있는지 보인다(접속 표시).
   - 저장은 버전 번호(낙관적 잠금)로 충돌을 감지한다. 서로 다른 단계를 고친 경우는 자동으로 합치고, 같은 단계를 고친 경우는 사용자에게 고르게 한다.
   - 단계나 캔버스 위치에 댓글 스레드를 달 수 있다(멘션, 해결 처리).
2. **이미지 만들기·파일 출력**
   - 이미지 생성 단계, 그리고 글·표를 CSV·XLSX·DOCX 같은 파일로 만드는 단계를 둔다.
   - 만든 파일은 실행 결과·챗·일괄 실행 결과에서 내려받을 수 있다. 파일은 앱 실행으로 만들어진 것만 공개 경로로 줄 수 있다.
3. **서비스 이벤트 트리거**
   - Slack·GitHub·Shopify·Telegram·Jira·Typeform의 이벤트로 흐름을 시작한다.
   - 서비스별 서명 확인, 이벤트 거르기, 받은 값을 입력 칸에 연결하는 설정, 샘플로 시험하는 기능이 있다.
4. **사람 단계 보강**
   - 처리를 다른 사람·역할에게 **전달**할 수 있고 전달 이력이 남는다.
   - 시간이 지나면 정해 둔 대로 처리한다(승인·반려·상위 역할로 올리기·'시간 초과' 갈래로 계속). 기한 전에 알림도 보낸다.
5. **관측 도구 확대**
   - Opik·Arize·Phoenix·W&B Weave와 OpenTelemetry(OTLP)로 실행 기록을 보낸다.
6. **키 여러 개 분산·공급자 폴백, 재정렬 전용 모델**
   - 한 공급자에 키를 여러 개 두고 나누어 쓰거나 한도 오류 때 다음 키로 넘어간다. 공급자가 실패하면 정해 둔 다른 공급자로 넘어간다.
   - 지식 검색의 재정렬에 전용 모델(Cohere·Jina·Voyage)을 쓸 수 있다.
7. **지식 처리 캔버스·이미지 포함 문서 검색**
   - 문서 처리 순서를 그림(단계 연결)으로 편집한다.
   - 문서 안의 이미지를 뽑아 이미지 설명(비전 모델)으로 색인해 검색에 쓴다.

## 이번에도 하지 않는 것
SSO·SCIM, 결제·요금제, 다중 워크스페이스 관리, 고객 키 관리(BYOK), 쿠버네티스·Terraform 배포, 사용자 정의 역할, 개인 드라이브(OAuth), 제3자 플러그인 등록.

## 영향
- 마이그레이션 0015~0019를 쓸 수 있다(댓글·접속 표시, 사람 단계 이력, 키 가중치, 이미지 조각 등). 모두 추가만 한다.
- 이미지 생성·비전·재정렬 전용 모델은 실제 키로 확인하지 못하고 가짜 서버로만 확인한다.
- 동시 편집은 같은 서버 한 대 안에서 Redis 알림으로 구현한다(서버가 여러 대여도 Redis를 공유하면 동작).
