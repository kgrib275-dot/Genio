# ADR 0014. 운영 준비 1차 — 실서비스 전에 꼭 필요한 것

- 상태: 채택
- 날짜: 2026-11-18

## 배경
실서비스에 필요한 기능과 요즘 흐름에 맞는 기능 후보를 모아(`docs/feature-candidates-2026-11-18.html`) 그중 "실서비스 전에 꼭" 묶음 8건을 순서대로 진행하기로 했다(2026-11-18 승인). 대상은 A1·A2·A9·B1·B2·B6·A6·A3이다.

## 결정
1. **A1 속도 제한**: 이미 Redis를 쓰고 있었다(11-05 메모는 옛 상태). 보강만 했다: 0.5초 제한 시간, Redis 오류 뒤 10초 메모리로 세기, incr·expire를 한 번에 보내기, 시스템 상태 '속도 제한'.
2. **A2 예약 실행 분리**: celery beat를 `scheduler` 서비스로 떼고, 워커는 실행만 한다. 주기 작업마다 Redis 표시(한 주기 한 번 + 실행 중 겹침 금지)를 남겨 beat가 둘 떠도 중복되지 않는다. 시스템 상태 '예약 실행'.
3. **A9 워크스페이스 한도**: 동시 실행(전체·앱당)·분당 실행·파일 저장 용량. 실행 한도를 넘으면 **실패시키지 않고 기다렸다 시작**한다(5초마다 다시 큐, 최대 30분). 바로 실행 모드(시험·로컬)에서는 확인하지 않는다. 설정은 `settings["limits"]`라 마이그레이션이 없다.
4. **B1 보안 남은 항목(F3~F21)**: 2026-11-06 보고서 §3.2 그대로. F9는 조치 불필요로 남겼다.
   - F12는 계획한 "시간 제한"이 파이썬 `re`로는 불가능해(도는 중 멈출 수 없음) 위험한 모양(반복의 반복·역참조)을 저장할 때 거절하는 방식으로 바꿨다. `regex`·`re2` 라이브러리는 넣지 않았다.
   - F18 새로고침 토큰 회전에 마이그레이션 0019(열 추가만, downgrade 있음).
   - F21은 CSP `img-src`에서 `https:`를 빼고, 챗 답변 속 외부 그림을 링크로만 보여 준다(그림 주소로 대화 내용을 내보내는 프롬프트 주입 수법 차단).
5. **B2 개인정보 가리기**: 한국 개인정보 모양 6종. 기록 화면·외부 추적에서는 **보여 줄 때만** 가리고 저장 원본은 그대로 둔다(되돌릴 수 있게). AI로 보내기 전에는 `[전화번호1]`처럼 바꾸고 답에서 되돌린다. 워크스페이스 설정과 AI 단계별 옵션 둘 다 둔다.
6. **B6 AI 기본법 대응**: 챗 화면 'AI가 답해요' 안내(기본 켜짐), 만든 그림의 파일 정보·선택적 보이는 표시, 워드·엑셀 문서 속성. 법률 검토를 대신하지 않으며 표시 방식은 `services/ai_label.py` 한곳에 모았다.
7. **A6 관측**: JSON 로그(요청 번호)와 `/metrics`. 계획에서는 `prometheus_client`를 쓰려 했으나, 프로세스 4개의 값을 합치려면 다중 프로세스 모드 설정이 필요하고 requirements가 바뀌면 이미지를 다시 빌드해야 해(이 PC 메모리 문제) **라이브러리 없이 Redis에 함께 세고 글 형식을 직접 만드는** 쪽으로 바꿨다. Prometheus·Grafana는 선택 프로필 `monitoring`.
8. **A3 외부 백업·복구 연습**: 워커가 한 시간마다 최근 백업을 바깥 S3 호환 저장소에 올린다(백업 컨테이너에는 S3 도구가 없어서). 매주 임시 DB에 실제 복구해 보는 연습을 자동으로 한다.

## 대안
- A9 한도 초과를 바로 실패시키기: 사용자가 다시 눌러야 하고 예약·외부에서 받기는 잃어버린다. 기다리기로 했다.
- B2를 저장할 때 가리기: 상담원 응대·AI 기억에 원문이 필요하고 되돌릴 수 없어 보여 줄 때 가리기로 했다.
- A3 백업 컨테이너에 aws-cli 넣기: 이미지를 따로 만들어야 해서 워커(boto3 있음)가 올리게 했다.

## 하지 않은 것(후보로 남김)
- 시점 복구(PITR, WAL 보관): 하루 한 번 백업이라 최악의 경우 하루치가 사라질 수 있다.
- react-router v7 업그레이드(보통 2건): 범위가 커서 따로.
- SMTP 등 메일 서버 연결의 DNS 재바인딩: 포트가 25·465·587·2525로 묶여 있어 영향이 작아 남겼다.

## 영향
- **운영 반영 때 꼭**: `docker compose up -d`로 반영한다(`restart api worker`만 하면 scheduler가 생기지 않아 **예약 실행이 멈춘다**). api가 뜰 때 마이그레이션 0019가 돈다. backup 서비스도 다시 만들어야 복구 연습 스크립트가 붙는다.
- 웹 화면 수정(F21 그림 링크, 개인정보 설정, AI 안내 문구, 한도 칸, 토큰 회전 대응)은 `start_genio.bat -Rebuild`가 필요하다. nginx CSP도 웹 이미지에 들어 있다.
- 실제 계정·환경으로 확인하지 못한 것: 바깥 S3 업로드, 실제 복구 연습(Docker가 꺼져 있었음), Prometheus·Grafana 화면, 여러 워커에서의 예약 중복 방지(가짜 Redis로만 시험).
