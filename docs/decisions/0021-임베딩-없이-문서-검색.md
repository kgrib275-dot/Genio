# 0021. 임베딩 연결이 없어도 문서를 쓸 수 있게(단어 검색 전용 저장)

- 상태: 채택
- 날짜: 2026-11-23

## 배경
실제 AI 키(Anthropic)만 등록한 회사에서 문서를 올리면 모두 "검색용으로 바꿀 AI 연결이 없어요"로 실패했다.
Anthropic은 임베딩 API가 없어서, 가장 흔한 용도인 "내 문서로 챗봇"이 OpenAI 키 없이는 시작도 못 했다(실사용 점검에서 발견).

## 결정
- 임베딩 연결(OpenAI·호환 API)이 없으면 문서를 **벡터 없이 조각만 저장**하고 `keyword_only` 표시를 남긴다(상태는 `ready`).
- 검색은 방식이 벡터·혼합이어도 **단어 검색으로 자동 전환**한다. 임베딩 연결이 있으면 지금처럼 동작한다.
- 문서 목록에 "단어로 찾는 검색만 쓸 수 있어요 … 키를 등록하고 '다시 처리'를 누르면 뜻 검색도 돼요" 안내를 보여 준다.
- 임베딩 연결이 있는데 키가 틀리거나 호출이 실패하는 경우는 이전처럼 오류로 알린다(`NoEmbeddingError`만 대체).

## 대안
- OpenAI 키를 필수로 안내만 하기: 첫 사용에서 막혀 기각.
- 로컬 임베딩 모델 내장: 이미지 크기·운영 부담이 커서 이번에는 기각(후속 후보).

## 영향
- 단어 검색은 질문과 문서가 같은 단어를 쓸 때 잘 찾고, 뜻이 같고 단어가 다르면 놓칠 수 있다.
- 나중에 임베딩 연결을 등록하면 문서를 '다시 처리'해야 뜻 검색이 된다(자동 재처리는 하지 않는다).
