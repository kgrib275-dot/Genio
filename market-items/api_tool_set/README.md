# API 도구(OpenAPI) 연결 정보

OpenAPI 3 명세(JSON·YAML)를 가져와 API의 기능을 **도구**로 만들어요.

## 쓰는 법
1. 연결 정보 화면 > **API 도구(OpenAPI) 가져오기**에서 명세 주소나 명세 글을 넣어요.
2. 가져올 도구를 고르고(최대 200개), 기본 주소와 인증(HTTP 인증 정보)을 정해 저장해요.
3. 흐름에서 **API 도구 호출** 단계를 추가하고 묶음과 도구를 골라 값을 넣어요.

## 알아 둘 것
- 명세는 1MB 이하, 같은 문서 안의 참조(`$ref: #/…`)만 풀어 줘요.
- 인증 값은 명세에 적지 않고 **HTTP 인증 정보** 연결 정보로 따로 보관해요.
- 사내망·내부 주소는 막혀 있어요.
