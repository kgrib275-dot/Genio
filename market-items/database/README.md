# 데이터베이스 (PostgreSQL·MySQL)

회사 DB에서 값을 **조회**하거나 행을 **추가·수정·삭제**해요.

- 조회는 `SELECT` 한 문장만, 최대 500행, 15초 안에 끝나야 해요(읽기 전용).
- 값은 문장에 직접 이어 붙이지 말고 `%(이름)s` 자리에 두고 **넣을 값**에 따로 적으세요. 예: `SELECT * FROM orders WHERE id = %(id)s`, 넣을 값 `{"id": "{{n1.order_id}}"}`
- 사내망(내부 IP)의 DB는 기본으로 막혀 있어요. 관리자가 **연결 정보 > 허용할 내부 주소**에 호스트를 등록하면 쓸 수 있어요.
- 연결 정보를 만든 뒤 **연결 테스트**로 접속을 확인하세요.
