# MCP 서버 연결 정보

외부에서 운영하는 **MCP(Model Context Protocol) 서버**의 도구를 흐름에서 불러 쓰게 해 줘요.

## 쓰는 법
1. 연결 정보 화면 > **MCP 서버 연결하기**에서 서버 주소(`https://…`)와 접속 토큰을 넣어요.
2. **연결 테스트**를 누르면 그 서버가 가진 도구 이름과 설명이 보여요.
3. 흐름에서 **외부 도구 호출(MCP)** 단계를 추가하고, 서버와 도구를 골라 값을 넣어요.
   에이전트 단계는 도구 종류를 `mcp`로 두면 그 서버의 도구를 스스로 골라 써요.

## 알아 둘 것
- 규격은 Streamable HTTP(JSON-RPC)예요. 주소는 서버 설명서의 MCP 주소를 쓰세요.
- 토큰은 암호화해 저장하고 화면에는 `****abcd`로만 보여요.
- 사내망·내부 주소는 막혀 있어요(외부에서 열린 주소만).
