# 네이버 클라우드 SENS 커넥터

네이버 클라우드 SENS로 문자(SMS·LMS)를 보내요.

## 준비
1. 네이버 클라우드 콘솔에서 **SENS** 프로젝트를 만들고 **서비스 ID**를 확인해요.
2. 마이페이지 > **인증키 관리**에서 Access Key / Secret Key를 만들어요.
3. SENS에서 **발신번호**를 등록해요.

## 동작
- **문자 보내기**: `to`, `content`(45자가 넘으면 LMS로 자동 전환)

연결 테스트는 입력 형식만 확인해요(문자가 실제로 나가는 호출 말고는 확인할 방법이 없어요).
