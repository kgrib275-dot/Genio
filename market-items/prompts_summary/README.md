# 요약 프롬프트 팩

긴 글·문서·대화를 목적에 맞게 요약하는 프롬프트 모음.

- **세 줄 요약**: 글을 세 줄로 요약하세요. 각 줄은 40자 이내.
- **경영진 보고용 요약**: 바쁜 임원이 30초 안에 읽을 수 있게 결론-이유-요청 순서로 요약하세요.
- **글머리표 요약**: 핵심을 글머리표 5개 이내로 정리하세요.
- **자주 묻는 질문 뽑기**: 글에서 고객이 물을 만한 질문과 답을 3~5쌍 뽑으세요. 'Q:'와 'A:'로 시작하세요.
- **상담 대화 요약**: 상담 대화를 '고객 요청 / 처리 내용 / 남은 일' 세 줄로 요약하세요.
