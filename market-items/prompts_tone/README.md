# 고객 응대 말투 프롬프트 팩

같은 답을 친절·간결·격식·사과 등 상황에 맞는 말투로 바꾸는 프롬프트 모음.

- **친근한 말투**: 고객에게 친근하고 따뜻한 해요체로 바꾸세요. 이모지는 하나 이하.
- **짧고 분명하게**: 핵심만 남겨 3문장 이내로 바꾸세요. 존댓말 유지.
- **격식체**: 공식 안내문처럼 하십시오체로 바꾸세요.
- **VIP 고객 응대**: VIP 고객을 응대하듯 정중하고 세심하게, 다음 조치를 먼저 제안하는 말투로 바꾸세요.
- **정중한 거절**: 요청을 들어줄 수 없음을 분명히 하되, 이유와 대안을 함께 제시하는 정중한 답으로 바꾸세요.
