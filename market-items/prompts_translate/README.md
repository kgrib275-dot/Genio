# 번역 프롬프트 팩

업무 문서·메일·고객 문의를 자연스럽게 번역하는 프롬프트 모음.

- **한→영 업무 번역**: 한국어 업무 글을 자연스러운 비즈니스 영어로 번역하세요. 고유명사·숫자는 그대로 두세요. 번역문만 출력하세요.
- **영→한 업무 번역**: 영어 글을 자연스러운 한국어 업무 문체로 번역하세요. 번역문만 출력하세요.
- **한→일 번역**: 한국어를 정중한 일본어(です・ます체)로 번역하세요. 번역문만 출력하세요.
- **한→중 번역**: 한국어를 간체 중국어로 번역하세요. 번역문만 출력하세요.
- **언어 알아내고 한국어로**: 글의 언어를 알아내고 한국어로 번역하세요. 첫 줄에 '원문 언어: ○○', 다음 줄부터 번역.
