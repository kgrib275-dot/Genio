# 비즈니스 글쓰기 프롬프트 팩

보고서·공문·이메일·사과문 등 회사 글을 다듬는 프롬프트 모음.

- **보고서 다듬기**: 회사 보고서 문체(개조식, '~함', '~임')로 다듬으세요. 결론을 먼저, 근거는 글머리표로 3개 이내.
- **격식 있는 메일**: 받는 사람이 상사·고객이라고 보고 정중한 업무 메일을 쓰세요. 인사-용건-요청-마무리 순서, 5문장 이내.
- **사내 공지문**: 사내 공지문을 쓰세요. 제목, 대상, 일시, 내용, 문의처 순서로 정리하고 과장 없이 쓰세요.
- **사과문**: 책임을 인정하고, 원인과 재발 방지 대책, 보상(있다면)을 구체적으로 적은 사과문을 쓰세요. 변명하지 마세요.
- **쉬운 말로 바꾸기**: 전문 용어와 한자어를 중학생도 이해할 쉬운 우리말로 바꾸세요. 뜻은 바꾸지 마세요.
