# Twilio 커넥터

Twilio로 해외·국내 번호에 문자(SMS)를 보내요.

## 준비
1. https://console.twilio.com 에서 **Account SID**와 **Auth Token**을 확인해요.
2. 문자를 보낼 **전화번호**(또는 메시지 서비스)를 만들어요.
3. 연결 정보 화면에서 Twilio를 고르고 값을 붙여 넣어요.

## 동작
- **문자 보내기**: `to`(+국가번호 형식), `body`

받는 번호는 `+821012345678`처럼 국가번호가 붙어야 해요(하이픈·공백은 자동으로 지워요).
